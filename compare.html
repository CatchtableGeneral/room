이번 개선안에 들어간 것

  • 사용 가능 기준 통일 — 현황판 5분 / 방 화면 15분으로 서로 달랐던 것을 15분으로. 두 화면이 다른 말을 하던 문제
  • 종일 일정 표시 — 00:00 – 00:00 → 종일
  • '예정 없음' 중복 제거 — 다음 회의가 없으면 우측 칼럼을 숨기고 현재 상태 카드가 전폭 사용
  • 생존신호 숨김 — "11일 지속" 같은 운영자용 표시는 ?dbg=1 일 때만
  • Mac 카드 통합 — 1줄짜리 빈 카드를 없애고 유선 카드 하단 안내로. 유선:무선 = 1:1 균형
  • 대비 개선 — 현황판 회의명 3.90:1 → 5.9:1, 브랜드 오렌지는 색 유지하고 굵기만 ↑
  • 글씨 크기 32종 → 8종 — 11.5 / 12.5 같은 눈으로 구분 안 되는 값들 정리
  • 모서리 19종 → 5종, 카드 그림자 2종으로
  • 현황판은 카드가 19개라 조밀 스케일(한 단계 아래)을 따로 적용
  • 에티켓 축소 · 쪽방 문구 · 상태별 레이아웃은 제외(하지 않기로 한 항목)
